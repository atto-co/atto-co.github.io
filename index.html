AttoLang · independent language project

Atto source → compiler Wasm → executable Wasm

The experimental playground aims to compile source code entirely within the browser. Its first milestone is a limited integer-language compiler—not proof of full language, actor, ownership or backend support.

Playground availability depends on the language website and its independently verified static deployment. No user source needs to be sent to an Atto compilation service.

Optional commercial infrastructure · planning stage

Proposed Atto Cloud service areas

These projects are experimental service foundations, not evidence of a deployed or production-ready cloud. AttoLang local execution does not depend on a hosted Atto account or compilation server.

  • Control plane — tenant and application lifecycle management.
  • Build farm — isolated builds and artifact provenance.
  • Runtime hosting — tenant execution boundaries and resource quotas.
  • Deployment service — staged releases, health gates, and rollback.
  • Observability — tenant-scoped operational telemetry.

Review each repository and its draft proposals to distinguish planned functionality from tested implementations.
