AttoLang · independent language project

Atto source → compiler Wasm → executable Wasm

The experimental playground aims to compile source code entirely within the browser. Its first milestone is a limited integer-language compiler—not proof of full language, actor, ownership or backend support.

Playground availability depends on the language website and its independently verified static deployment. No user source needs to be sent to an Atto compilation service.
